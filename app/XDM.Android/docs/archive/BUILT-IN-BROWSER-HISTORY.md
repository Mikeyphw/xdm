# Retired Built-in Browser History

The built-in Android browser was introduced in Phase 18 and promoted to a separate product surface during Phases 37–50. It was implemented with Android WebView and accumulated tabs, history, bookmarks, private mode, permissions, resource inspection, and browser-specific download rules.

The browser runtime, activity, route, launcher entry, persistence, resources, and active validation contracts were removed by the browser-removal program. Downloader work that landed during the same period remains active, including external handoff, Add Download review, media resolution, queue execution, native and aria2 engines, Termux integration, offline library, playback, diagnostics, and redaction.

This file is historical context only. It is not an active architecture contract and must not be used to reintroduce a built-in browsing engine.
