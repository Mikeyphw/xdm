# Phase 47: Browser Permission UX + Settings Polish

Phase 47 adds browser-scoped permission review and settings polish without changing transfer or media engines.

## Scope

- Site permission card for camera, microphone, location, protected-media-id style requests.
- Review-first Grant once / Deny / Dismiss actions.
- Recent permission decisions shown in Browser.
- Private tabs warn that permission grants are one-shot and session-scoped.
- Browser settings adds reset settings and clearer site-capability copy.

## Safety

- No durable permission allow-list.
- No new route.
- No Room migration.
- No adblock/proxy/DNS.
- No transfer or media execution changes.
