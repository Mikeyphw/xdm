# Phase 48: Browser Resource Inspector

Phase 48 expands the browser library into a page resource inspector. It keeps resources review-first and separate from queue execution.

## Scope

- Resource inspector panel.
- Filters for All, Media, Direct, Observed, Unknown.
- Resource rows with Open, Add, and Inspect media.
- Source-page context.

## Safety

- No silent auto-queue.
- No new route.
- No Room migration.
- No transfer engine changes.
- No media execution changes.
